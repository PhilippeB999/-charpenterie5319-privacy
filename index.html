Questions fréquentes

Comment obtenir un code d'accès ?
Le code d'accès est fourni gratuitement par l'enseignant ou l'enseignante aux élèves inscrits au cours. Il n'y a aucun coût et aucun achat n'est requis dans l'application.

L'application collecte-t-elle mes données ?
Non. Consultez notre politique de confidentialité pour plus de détails.
